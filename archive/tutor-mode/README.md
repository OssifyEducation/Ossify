# Standalone Tutor Mode viewer (archived 19 Oct 2026)

`tutor-mode.html` was an early single-question viewer (`tutor-mode.html?question_id=…`) with its own
navy styling and fonts (Libre Baskerville / DM Sans). Nothing on the site linked to it, and Tutor Mode
now lives in the shared renderer `js/ossify-tutor.js` used by practice, exam review, the weekly review and
the front-page sample question. Kept here (not deployed: `archive/` is in `.vercelignore`) in case it is
useful as a reference. To restore, move it back to the repository root.
